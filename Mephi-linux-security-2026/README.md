## Выполненные разделы

### 1. Управление пользователем

Создан пользователь `user1` с UID `1234`.

Пользователь включён в группу `students`. Для учётной записи настроено обязательное изменение пароля каждые 3 месяца.

### 2. Мониторинг

Выполнен поиск файлов с установленным битом SUID.

Также выполнен поиск процессов, у которых эффективный UID (`EUID`) равен `0`, а реальный UID (`RUID`) принадлежит обычному пользователю. Для демонстрации использован процесс `passwd`.

### 3. Механизм set-UID

В качестве утилиты выбран `/usr/bin/cat`.

Копия утилиты размещена в домашнем каталоге пользователя:

```text
/home/user1/cat
```

На копию установлен бит set-UID. После этого пользователь `user1` получил возможность выполнить операцию, требующую привилегий root.

### 4. Linux capabilities

В качестве утилиты выбран `/usr/bin/chown`.

Копия размещена:

```text
/home/user1/chown
```

Для неё установлена capability:

```text
cap_chown=ep
```

Это позволило пользователю `user1` изменить владельца тестового файла без запуска самой утилиты от имени root.

### 5. Sudo

Для пользователя `user1` настроено выполнение:

```text
/bin/timedatectl
```

через `sudo`.

В результате пользователь `user1` смог отключить автоматическую синхронизацию времени и изменить системное время.
